Requirements: Python 3.8 or later. No third-party packages.

Run each program separately in VS Code terminal:
python task1_bst_claim_ids.py
python task2_claim_hashing_duplicates.py
python task3_claim_approval_graph.py
python task4_consecutive_claim_spike_days.py
python task5_merge_sorted_claim_lists.py

Each file is independent and prints its own task heading, sample output,
and relevant edge-case tests for screenshots.

Task 2 normalization removes whitespace and ignores case in policy numbers.
Hyphens are retained. The incident date must match exactly.
Task 4 finds the longest uninterrupted run of days with claim counts strictly
greater than 100. All sample data is fictional.
