REQUIREMENTS
------------
Python 3.8 or later. No third-party packages are required.

HOW TO RUN
----------
Open this folder in VS Code. Open Terminal > New Terminal.
Run each task separately:

python task1_bst_hub_codes.py
python task2_parcel_tracking_hashmap.py
python task3_hub_routes_bfs_dfs.py
python task4_sliding_window_delivery_counts.py
python task5_palindrome_route_description.py

SCREENSHOTS
-----------
Run one file at a time and capture the terminal output for that task.
Task 5 also accepts a route description typed by the user.
You can edit the sample inputs inside each file to test other cases.

NOTES

All sample data is illustrative. The programs are independent, so each can
be executed and screenshotted separately. The graph used in Task 3 is also
